# TraceHunt AI

**TraceHunt AI** is an AI-powered observability and incident intelligence platform built to monitor APIs, analyze logs, detect anomalies, and automate root cause investigation using AI.

It helps engineering teams reduce downtime by providing real-time monitoring, alerting pipelines, operational insights, and AI-generated incident summaries through scalable event-driven architecture.

Built with **Next.js**, **FastAPI**, **PostgreSQL**, **Redis**, **Docker**, and intelligent incident analysis workflows.

---

## 🚀 Core Features
- **API Health Monitoring**: Real-time status checks and latency tracking.
- **Real-Time Log Aggregation**: Centralized logging for distributed systems.
- **Error Detection & Alerting**: Immediate notifications on system failures.
- **AI Root Cause Analysis**: Automated investigation using LLMs.
- **Incident Timeline Generation**: Visualizing the sequence of events.
- **Failure Pattern Detection**: Identifying recurring system issues.
- **Rate Limit Monitoring**: Tracking API usage and thresholds.
- **Queue-Based Event Processing**: Scalable background task management.
- **Team Dashboard**: Unified view for engineering teams.
- **Deployment Monitoring**: Tracking health during release cycles.
- **Audit Logs**: Secure tracking of system changes.
- **Performance Analytics**: Deep insights into system efficiency.

## 🛠 Tech Stack

### Frontend
- **Framework**: Next.js
- **Styling**: TailwindCSS

### Backend
- **Language/Framework**: FastAPI
- **Database**: PostgreSQL
- **Cache & Queues**: Redis

### AI Layer
- **Model**: OpenAI
- **Logic**: Incident intelligence engine

### DevOps & Infrastructure
- **Containerization**: Docker
- **Orchestration**: Kubernetes
- **CI/CD**: GitHub Actions
- **Monitoring**: Prometheus, Grafana
- **Cloud**: Amazon Web Services (AWS)
